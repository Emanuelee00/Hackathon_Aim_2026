# Chez Marthe

Before any task, read `docs-md/HANDOFF.md` (current state, decisions and why, next steps) and follow
`docs-md/Guide.md` (working rules). The user writes in Italian; the repo stays in English (code, comments,
commits), French for site content and the team's documents. The repository is public: never write secrets.

Checks before a commit: `make check`. Start the app: `make run` (or `make dev` after a build);
`make` alone lists the commands.
